# Personal Portfolio

A modern, dark-themed personal portfolio built with **Next.js 16** (App Router), **TypeScript**, and **Tailwind CSS**.

## Features

- 🏝️ **Island Navbar** — floating, centered, `rounded-2xl` with `backdrop-blur-md` and active-section tracking via scroll
- 💻 **Hero + Fake Terminal** — animated typewriter terminal with macOS-style window chrome, blinking cursor, and a step-by-step command sequence
- 📊 **About / Skills** — stats grid & skill progress bars grouped by Backend, Frontend, Cloud, and DevOps
- 🚀 **Projects** — 6 mocked full-stack project cards (CloudOps Dashboard, MicroCommerce, DataFlow Pipeline, DevTrack, SmartInventory, AuthGuard)
- 📬 **Contact** — form with success-state animation + social links (GitHub, LinkedIn, Twitter)
- 🌑 Dark navy theme (`#080c14`) with cyan/indigo accent gradient
- ✨ Scroll-reveal animations via vanilla `IntersectionObserver` (no extra libraries)

## Tech Stack

Next.js · TypeScript · Tailwind CSS · React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
